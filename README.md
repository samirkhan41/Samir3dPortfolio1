# 🌐 Samir Khan — 3D Portfolio

A modern and responsive **full-stack developer portfolio website** designed to showcase my skills, projects, experience, and technical journey.

The portfolio combines a clean developer-focused interface with modern visual elements, animations, and responsive layouts to provide an engaging browsing experience.
